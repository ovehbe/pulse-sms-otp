# Privacy Policy — Pulse SMS OTP Copy

**Last updated:** 2026-09-13

Pulse SMS OTP Copy is a Chrome extension that helps you copy one-time passcodes (OTP / SMS verification codes) from the Pulse SMS web app conversation list.

## Data collection
This extension does **not** collect, store, transmit, or sell any personal data.

- It runs only on Pulse SMS web pages (`pulsesms.app` and related subdomains).
- When you click a copy button, it reads the visible message preview text in that conversation row in your browser and copies a detected code to your local clipboard.
- Nothing is sent to any server operated by the extension author.
- There are no analytics, ads, accounts, or remote APIs.

## Permissions
- **clipboardWrite**: used only when you click a copy button, to put the OTP on your clipboard.
- **Host access to Pulse SMS sites**: required so the extension can show buttons on the conversation list.
